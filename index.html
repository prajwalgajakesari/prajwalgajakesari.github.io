    Node 02 · Ingest

    MotoGenie: I mapped India for riders.

    Every dot is a real place I collected, cleaned and geocoded across all 28 states.

    I scraped and stitched together sources no single map had: routes, passes, fuel, permits and hidden gems. The raw crawl was ~75 GB. What survived is a catalog a rider can actually trust.

    14,738 places

    3,246 routes

    The dataset behind MotoGenie, snapped to a 5 km grid for this view. Enriched with regions, seasons, permits, altitude and a rule-based ride score.

    Node 03 · Enrich · Manali → Khardung La

    Raw points become terrain.

    This ridge is real: the elevation profile of the Manali to Khardung La route in my dataset, 378 km, topping out at 5,411 m.

    Enrichment is where a pipeline earns its keep. I join each route against altitude, season windows and permit zones, so the app can warn you before the road does.

    Δ 5.4 km vertical

    Altitude, seasonality and inner-line permits, computed per route. Steps like enrich_altitude and enrich_permits run over the whole catalog.

    Node 04 · Model

    The part I do for a living.

    Points snap into a schema. This is the day job: lakehouses, star schemas and catalogs that stay correct at scale.

    Trino · ADLS Gen2 · Purview

    Data platform

    I run query engines and a governed lakehouse on Azure: Trino over Data Lake Gen2, catalog and lineage in Purview. Every number a dashboard shows can be traced back to its source.

    Python · dbt · Claude skill

    DataForge ↗

    AI-assisted data modeling from the terminal: profile a schema, find normal-form violations from 1NF to BCNF, design a star schema, and generate a dbt project that passes validation.

    FastAPI · Postgres · deterministic engine

    CivilOS

    An AI-native platform for India's civil contractors, built around government RA-billing. Money is integer paise and a deterministic engine computes every number; the model never does. 1,000+ tests, tenant isolation, bilingual audited PDFs.

    Docker · Trino · Azure

    Trino + ADLS setup ↗

    A reproducible Trino 474 deployment with a Hive file metastore and native ADLS Gen2 access, with example SQL for external schemas and tables.
